PDF 한국어 맞춤법 검사기란?

PDF 한국어 맞춤법 검사기는 PDF 문서의 한국어 맞춤법과 띄어쓰기를 자동으로 검사하여 오류를 표시해주는 무료 온라인 서비스입니다. 바른(Bareun) AI API를 활용하여 높은 정확도로 맞춤법 오류를 감지하고, 각 오류에 대한 수정 제안을 주석으로 추가하여 제공해드립니다.

회원가입 없이 바로 사용할 수 있으며, 업로드된 파일은 검사 완료 후 즉시 삭제되어 개인정보 보호도 철저합니다. 학생, 직장인, 작가, 연구자 등 정확한 한국어 문서 작성이 필요한 모든 분들께 유용합니다.

사용 방법

  1. PDF 파일 업로드 - 검사할 PDF 파일을 선택하거나 드래그하세요 (최대 20MB)
  2. 이메일 입력 - 결과를 받을 이메일 주소를 입력하세요
  3. 검사 시작 - "맞춤법 검사 시작" 버튼을 클릭하세요
  4. 결과 다운로드 - 검사 완료 후 PDF 파일이 자동으로 다운로드됩니다

누가 사용하면 좋을까요?

  • 학생 - 과제, 리포트, 논문 제출 전 맞춤법 확인
  • 직장인 - 업무 문서, 제안서, 보고서 교정
  • 작가/에디터 - 원고, 기고문 최종 검수
  • 연구자 - 연구 논문, 학술 자료 맞춤법 검증
  • 번역가 - 번역 결과물 한국어 문법 확인

자주 틀리는 맞춤법

❌ "되요" → ⭕ "돼요"

'되다'에 '-어요'가 붙으면 '돼요'가 됩니다.

❌ "안되" → ⭕ "안 돼"

'안'과 '되다'는 띄어 쓰고, '되어'는 '돼'로 줄입니다.

❌ "어떻게 해" → ⭕ "어떡해" (또는 "어떻게 해")

'어떻게 해'를 줄이면 '어떡해'가 됩니다.

❌ "금새" → ⭕ "금세"

'금시에'가 줄어든 말로 '금세'가 맞습니다.

자주 묻는 질문 (FAQ)

Q. 업로드한 PDF 파일은 안전하게 보관되나요?

A. 네, 업로드된 파일은 맞춤법 검사 완료 후 즉시 서버에서 자동 삭제됩니다. 파일 내용은 서버에 저장되지 않으며, 복구가 불가능한 방식으로 영구 삭제됩니다.

Q. 검사 결과를 받는 데 얼마나 걸리나요?

A. 일반적으로 검사 완료 후 바로 PDF 파일이 다운로드됩니다. 파일 크기와 텍스트 양에 따라 처리 시간이 달라질 수 있으며, 보통 1~3분 내에 완료됩니다.

Q. 어떤 형식의 PDF 파일을 지원하나요?

A. 텍스트가 포함된 모든 PDF 파일을 지원합니다. 단, 스캔된 이미지 PDF는 텍스트 추출이 어려워 검사가 제한될 수 있습니다. OCR 처리된 PDF는 검사 가능합니다.

Q. 파일 크기 제한이 있나요?

A. 최대 20MB까지 업로드 가능합니다. 대부분의 문서는 이 크기 내에서 처리 가능하며, 용량이 큰 경우 파일을 분할하여 업로드해주세요.
